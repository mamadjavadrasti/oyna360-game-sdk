# نمای کلی — `@oyna360/game-sdk`

این سند برای **بازی‌سازی** است که می‌خواهد بازی‌اش را به oyna360 وصل کند.

---

## این SDK چه کار می‌کند؟

پل رسمی بین **بازی** و **پلتفرم oyna360**:

- گرفتن کاربر، سشن، اطلاعات بازی
- در صورت وجود: آواتار لابی و اطلاعات اتصال لابی (`lobby.wsUrl`, `roomId`)
- ثبت امتیاز، لیدربورد، دستاورد، کیف‌پول جِم (در حالت iframe / Production)

بازی را مجبور نمی‌کند موتور خاصی (Three، Babylon، Unity Web، …) داشته باشد.

---

## این SDK چه کار نمی‌کند؟

| کار | کجا |
|-----|-----|
| لابی ۳D، آواتار متحرک، چت لابی، WebSocket بازیکنان | `@oyna360/lobby-sdk` |
| سرور اختصاصی گیم‌پلی شما | سرور خودتان |
| ذخیره پسورد یا توکن دائمی داخل بازی | نباید انجام شود |

دو پکیج را قاطی یا fork-merge نکنید.

---

## معماری

```text
                    oyna360 Platform

           │                               │
      Production                      Direct Dev

                  @oyna360/game-sdk
                           │
                    SdkInitPayload
                           │
              ┌────────────┴────────────┐
              ▼                         ▼
     گیم‌پلی / امتیاز            @oyna360/lobby-sdk
     (score, wallet, …)          (لابی ۳D اختیاری)
```

---

## چه زمانی فقط game-sdk؟ چه زمانی هر دو؟

| نوع بازی | game-sdk | lobby-sdk |
|----------|:--------:|:---------:|
| امتیاز / سشن / جِم بدون لابی ۳D | لازم | نه |
| لابی ۳D قبل از مسابقه + بعداً گیم‌پلی | لازم | لازم |
| فقط تست UI بدون شبکه | — | `createDev()` لابی (Fake) |

---

## نسخه و سازگاری

- نسخه پکیج با `PlatformSDK.version` خوانده می‌شود.
- در ادمین بازی فیلد `minSdkVersion` را طوری بگذارید که با SDK نصب‌شده شما سازگار باشد.
- Semantic Versioning: تغییر breaking در major.
